# Version 1.0.0 source archives

These standalone packages contain the corresponding edition's source, original assets, tests, scripts, dependency lockfiles and documentation. They are generated from the tracked edition directories with `python3 scripts/package-source.py`.

| File | Contents |
| --- | --- |
| [DiskMosaic-1.0.0-Source.tar.xz](DiskMosaic-1.0.0-Source.tar.xz) | Full analysis edition |
| [DiskMosaic-Light-1.0.0-Source.tar.xz](DiskMosaic-Light-1.0.0-Source.tar.xz) | Compact edition |
| [SHA256SUM.txt](SHA256SUM.txt) | SHA-256 hashes for both source archives |

Extract an archive and follow its README to build it. The archive root contains a complete edition source tree. Toolchains, dependency caches, compiled packages and user runtime data are excluded.
