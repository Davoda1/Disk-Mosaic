# DiskMosaic 1.0.1 source archives

These standalone archives contain the complete source for each edition, including application assets, the Rust engine, dependency lockfiles, build scripts, regression tests, and documentation.

| Edition | Source archive |
| --- | --- |
| DiskMosaic | [DiskMosaic-1.0.1-Source.tar.xz](DiskMosaic-1.0.1-Source.tar.xz) |
| DiskMosaic Light | [DiskMosaic-Light-1.0.1-Source.tar.xz](DiskMosaic-Light-1.0.1-Source.tar.xz) |

Verify both archives with the [SHA-256 checksum manifest](SHA256SUM.txt). Extract the selected archive and follow its `README.md` and `docs/BUILDING.md` instructions. The new license-report regression tests run as part of the normal `npm test` suite.

The archives exclude compiled applications, downloaded dependencies, toolchains, local settings, and scan data. Application packages and release notes are available from the [1.0.1 release](https://github.com/Davoda1/Disk-Mosaic/releases/tag/v1.0.1).
